# THE LOST CULT

A terminal horror-adventure written in C. You wake trapped inside a church run
by a cult; explore the halls, solve a password lock, survive a ghost-escape grid,
a cursed card game and a very unpleasant kitchen — and try to get out before you
become one of them.

## ▶ Play in your browser

Once GitHub Pages is live, the game is playable on **Mac, Windows, Linux and
mobile** — no install, no compiler — here:

**https://camachoj-ds-exp.github.io/the-lost-cult/**

> Best on a desktop with a keyboard. Type your answers and press **Enter**;
> use **W A S D** to move in the ghost-escape section.

## How it works

The game is the same C program in [`LostCult.c`](LostCult.c). For the web it is
compiled to **WebAssembly** with [Emscripten](https://emscripten.org/) and runs
inside an [xterm.js](https://xtermjs.org/) terminal in the page.

| Piece | File |
| --- | --- |
| Original game (Windows console) | `LostCult.c` + the `*.txt` ASCII-art assets |
| Browser build of the game | `web/LostCult_web.c` (generated by `web/port.py`) |
| Web terminal page | `web/index.html` |
| Build + deploy pipeline | `.github/workflows/deploy.yml` |

`web/LostCult_web.c` is generated from `LostCult.c` by a small script that swaps
the Windows-only calls (`system("cls")`, `system("color …")`, `Sleep`, `getch`,
`scanf`) for browser-friendly equivalents. **The game logic is unchanged** — to
make edits, change `LostCult.c` and re-run:

```bash
python web/port.py
```

Every push to `main` rebuilds the WebAssembly and redeploys to GitHub Pages
automatically.

## Building the native Windows version

The original still compiles and runs on Windows exactly as before:

```bash
gcc -o LostCult LostCult.c
./LostCult.exe
```

(Requires the `*.txt` files to sit next to the executable.)
